Oke! Berikut **tabel ringkas contoh query CRUD (Create, Read, Update, Delete)** di **MySQL, PostgreSQL, SQL Server, dan Oracle** supaya perbedaan sintaksnya langsung kelihatan.

---

## **1. CREATE TABLE (Membuat tabel)**

| DB         | Sintaks                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| MySQL      | `sql CREATE TABLE users (id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(50)); `                       |
| PostgreSQL | `sql CREATE TABLE users (id SERIAL PRIMARY KEY, name VARCHAR(50)); `                                   |
| SQL Server | `sql CREATE TABLE users (id INT IDENTITY(1,1) PRIMARY KEY, name VARCHAR(50)); `                        |
| Oracle     | `sql CREATE TABLE users (id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, name VARCHAR2(50)); ` |

---

## **2. INSERT (Menambahkan data)**

| DB         | Sintaks                                           |
| ---------- | ------------------------------------------------- |
| MySQL      | `sql INSERT INTO users (name) VALUES ('Alice'); ` |
| PostgreSQL | `sql INSERT INTO users (name) VALUES ('Alice'); ` |
| SQL Server | `sql INSERT INTO users (name) VALUES ('Alice'); ` |
| Oracle     | `sql INSERT INTO users (name) VALUES ('Alice'); ` |

> INSERT dasar mirip semua DB, yang berbeda biasanya kalau pakai auto-increment/sequence.

---

## **3. READ (SELECT data)**

| DB         | Sintaks                                                                       |
| ---------- | ----------------------------------------------------------------------------- |
| MySQL      | `sql SELECT * FROM users LIMIT 10 OFFSET 5; `                                 |
| PostgreSQL | `sql SELECT * FROM users LIMIT 10 OFFSET 5; `                                 |
| SQL Server | `sql SELECT * FROM users ORDER BY id OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY; ` |
| Oracle     | `sql SELECT * FROM users OFFSET 5 ROWS FETCH NEXT 10 ROWS ONLY; `             |

---

## **4. UPDATE (Mengubah data)**

| DB         | Sintaks                                        |
| ---------- | ---------------------------------------------- |
| MySQL      | `sql UPDATE users SET name='Bob' WHERE id=1; ` |
| PostgreSQL | `sql UPDATE users SET name='Bob' WHERE id=1; ` |
| SQL Server | `sql UPDATE users SET name='Bob' WHERE id=1; ` |
| Oracle     | `sql UPDATE users SET name='Bob' WHERE id=1; ` |

> UPDATE dasar hampir sama semua DB.

---

## **5. DELETE (Menghapus data)**

| DB         | Sintaks                              |
| ---------- | ------------------------------------ |
| MySQL      | `sql DELETE FROM users WHERE id=1; ` |
| PostgreSQL | `sql DELETE FROM users WHERE id=1; ` |
| SQL Server | `sql DELETE FROM users WHERE id=1; ` |
| Oracle     | `sql DELETE FROM users WHERE id=1; ` |

---

## **6. UPSERT / INSERT OR UPDATE (Jika data sudah ada)**

| DB         | Sintaks                                                                                                                                                                                                                                            |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| MySQL      | `sql INSERT INTO users (id, name) VALUES (1, 'Alice') ON DUPLICATE KEY UPDATE name='Alice'; `                                                                                                                                                      |
| PostgreSQL | `sql INSERT INTO users (id, name) VALUES (1, 'Alice') ON CONFLICT (id) DO UPDATE SET name='Alice'; `                                                                                                                                               |
| SQL Server | `sql MERGE INTO users AS target USING (VALUES (1, 'Alice')) AS source (id, name) ON target.id = source.id WHEN MATCHED THEN UPDATE SET name=source.name WHEN NOT MATCHED THEN INSERT (id, name) VALUES (source.id, source.name); `                 |
| Oracle     | `sql MERGE INTO users target USING (SELECT 1 AS id, 'Alice' AS name FROM dual) source ON (target.id = source.id) WHEN MATCHED THEN UPDATE SET target.name = source.name WHEN NOT MATCHED THEN INSERT (id, name) VALUES (source.id, source.name); ` |

> Di sinilah perbedaan sintaks paling terlihat: MySQL & PostgreSQL punya shortcut, SQL Server & Oracle harus pakai `MERGE`.
